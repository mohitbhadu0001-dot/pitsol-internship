# Day 2 – HTML Portfolio

## About the Project
This project is a simple personal portfolio webpage created as part of my Week 1, Day 2 internship practice. It introduces me, highlights my technical skills, and provides a useful HTML learning resource.

## Features
- Navigation bar with Home, About, and Skills links
- About Me section
- Technical skills list
- Java logo image
- External HTML learning resource link
- Semantic HTML structure

## Technologies Used
- HTML5
- Git
- GitHub

## What I Learned
- Creating the basic HTML document structure
- Using headings, paragraphs, lists, and links
- Working with images and alternative text (`alt`)
- Using semantic elements such as `header`, `nav`, `main`, `section`, and `footer`
- Connecting navigation links to page sections using `id` and `href`
- Understanding accessibility attributes such as `aria-labelledby`
