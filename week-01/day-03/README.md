# Day 3 — HTML Forms, Validation & Accessible Tables

## Overview

This project is part of my PitSol Internship — Week 1, Day 3. It demonstrates my understanding of HTML forms, form validation, semantic tables, accessibility, and navigation between web pages.

## Pages Included

- **index.html** — Introduction to the project and topics I am learning.
- **registration.html** — Registration form with input fields, radio buttons, validation, and submission controls.
- **contact.html** — Contact information with email and phone details.
- **applications.html** — Sample applicants displayed in an accessible HTML table.

## Concepts Practiced

- HTML5 document structure and semantic elements.
- Forms and input controls.
- Labels, IDs, names, and input types.
- Validation attributes such as `required`, `pattern`, `maxlength`, `min`, and `max`.
- Radio buttons, textareas, and buttons.
- Tables using `thead`, `tbody`, `th`, `td`, and `scope`.
- Navigation using links.
- Basic web accessibility.

## Testing

I checked the pages for:

- Navigation links between pages.
- Labels associated with their input fields.
- Required fields and input validation.
- Radio button selection.
- Table headers and sample applicant data.
- Basic keyboard navigation.

## Limitations

This is an HTML practice project. The registration form does not store applicant data because no backend or database is connected. The applicants table contains sample data for learning purposes.
