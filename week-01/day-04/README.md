# Day 4 – CSS Styling and Services Page

## Overview
Today I worked on styling existing web pages using CSS and created a new Services page with three service cards.

## Tasks

### 1. Registration and Contact Pages
- Used a shared `style.css` file for styling.
- Defined CSS variables for primary color, text, background, border, and focus.
- Improved headings, spacing, and form field appearance.
- Worked on keyboard focus styles for accessibility.

### 2. Applications Page
- Styled the applications table.
- Added cell padding, borders, and header styling.
- Used alternating row background colors to improve readability.
- Kept table headings clear and meaningful.

### 3. Services Page
- Created `services.html`.
- Added three service cards: Starter, Growth, and Enterprise.
- Included sample prices, descriptions, and feature lists.
- Styled card borders, spacing, and buttons.
- Arranged cards vertically without using Flexbox or Grid.

## Design Decisions
1. Consistent colors help maintain a uniform appearance across pages.
2. Padding and margins improve spacing and readability.
3. Visible focus outlines help keyboard users identify focused elements.

## Technologies Used
- HTML5
- CSS3

## Learning Outcomes
- Practiced reusable CSS styling and CSS variables.
- Learned to style tables and service cards.
- Practiced basic keyboard accessibility and focus styling.
