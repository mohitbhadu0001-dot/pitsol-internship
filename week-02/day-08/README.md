# Week 2 – Day 8: JavaScript Functions, Scope & Reusable Logic

## Overview
Today I learned JavaScript functions, variable scope, reusable logic, function composition, and the Euclidean algorithm for calculating GCD and LCM.

## Topics Covered
- Function Declaration, Function Expression, and Arrow Functions
- Parameters and Arguments
- Return Values vs console.log()
- Global, Function, and Block Scope
- Variable Shadowing
- Default Parameters
- Guard Clauses and Input Validation
- Function Composition
- Pure Functions and Side Effects
- GCD and LCM using the Euclidean Algorithm
- Coprime Numbers
